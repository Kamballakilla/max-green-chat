# Структура проекта

Инструкция по установке и локальному запуску находится в [README](../README.md#локальный-запуск), сценарии проверки — в [TESTING.md](TESTING.md).

## Точка входа и интерфейс

`index.html` загружает `src/main.tsx`, который монтирует `App.tsx` внутри React StrictMode. `App.tsx` выбирает экран подключения или рабочую область активной сессии.

- `components/Login.tsx` — форма параметров подключения и вход в демо.
- `components/ChatWorkspace.tsx` — список диалогов, история сообщений и поле ввода.
- `components/NewChatDialog.tsx` — создание диалога по номеру телефона.
- `styles.css` — оформление и адаптация интерфейса для мобильных экранов.

## Данные и запросы

`types.ts` определяет типы учётных данных, диалогов и сообщений, а также интерфейс `ChatApi`. Реальный клиент `api/greenApi.ts` выполняет HTTP-запросы и проверяет ответы сервера. `api/demoApi.ts` реализует тот же интерфейс с локальными данными.

`lib/validation.ts` проверяет параметры подключения, номера телефонов и длину текста. `lib/notifications.ts` преобразует уведомления API в события приложения.

## Состояние сессии

`hooks/useChat.ts` связывает интерфейс с API, отправкой сообщений и получением уведомлений. `lib/chatReducer.ts` обновляет диалоги и сообщения, обрабатывает повторные события и статусы доставки.

`lib/polling.ts` последовательно получает и подтверждает уведомления через `ReceiveNotification` и `DeleteNotification`. При завершении сессии активные запросы отменяются.

## Проверки

В `src/test/` находятся тесты валидации, API-контрактов, переходов состояния, получения уведомлений и пользовательских сценариев. Команда `npm run check` запускает ESLint, тесты, проверку TypeScript и production-сборку.
